# PAATI & CO. — Demo storefront

A responsive, front-end-only South Indian sweets, snacks and coffee storefront inspired by the merchandising patterns of the reference website.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build step or dependencies are required. Google Fonts are loaded online; the site still works with fallback fonts offline.

## Included interactions
- Responsive navigation and mobile menu
- Product category filtering
- Product search and price sorting
- Pack-size/variant selection
- Add-to-cart and quantity updates
- Cart drawer with subtotal
- Newsletter demo interaction

## Important
This is a front-end demo. Checkout, accounts, inventory, shipping, tax, order management and newsletter storage are not connected. Product names, prices, testimonials and brand identity are fictional placeholders. Replace them before launch.
